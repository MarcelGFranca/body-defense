## ADDED Requirements

### Requirement: Start page
The start page SHALL show the animated fighters, a static title that glints every 10 seconds with a chime, and the buttons NEW GAME, CONTINUE, HOW TO PLAY and SETTINGS.

#### Scenario: Behaviour
- **WHEN** the game opens
- **THEN** the fighters hop facing each other, NEW GAME opens the level list and CONTINUE is off until a level is won
