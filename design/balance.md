# Balance data

Every number that decides how hard the game is, before and after the balance pass, and what 1000 recorded games say about it. Changed values show as `before → **after**`. Generated by `tools/write_balance_doc.py` from the data files and `playtests/`.

## 1. How the games were played

- Each recorded game is played by a bot that builds towers in one of ten ways: `smart`, `smart_calls` (also calls waves early), `damage_only`, `balanced_mix`, `few_strong` (half of the slots), `worst_slots` (worst coverage first), `random_a`, `random_b`, `support_heavy` (slow, root, block and mark towers) and `cheap` (only the cheapest tower).
- The bots have human-like noise (they build a little late, sometimes pick another tower or swap two slots).
- The games are run by the game itself without a screen and at high speed (the simulation has no randomness), 1000 games in about 4 minutes.
- **Before** = `baseline_1000` (1000 games, Medium, original numbers). **After** = `medium_1000`, `easy_1000` and `hard_1000` (1000 games each, final numbers). Each level has 100 games per difficulty, which is a margin of error of about ±10 points.
